# Pluto intelligence

Text chat, persisted customer conversations, bounded read-only data tools, weekly report history and explicit public web research are implemented. All paid flags default OFF. Local analysis remains available without sending records to a provider. Full note bodies, connector tokens and other customers' records never enter model context. Domain-specific sharing consent is separate from the selected question scopes. Facts and exact calculations remain immutable; model interpretations are labelled estimates or suggestions and validated against supplied references. No SQL, code or unrestricted action tools are exposed.

The initial provider uses the Responses API, strict structured output, `store:false`, standard service tier, a 20-second timeout and at most 1,400 output tokens. Configurable default `gpt-6-luna` costs USD $0.10/M input and $0.50/M output tokens according to [official model documentation](https://developers.openai.com/api/docs/models/gpt-6-luna). Unknown model names require explicit positive input/output microdollar rates. Confirm actual project availability and current prices before activation. ChatGPT Plus does not fund API requests.

Every paid request first atomically reserves requests, tokens, concurrency and conservative cost against customer and global budgets. Provider usage settles inside the same transaction as saved results. Failed or uncertain dispatch retains worst-case cost; replay keys never redispatch. Context and responses have byte limits. Providers never receive database credentials. Historical user messages are bounded conversational context, not evidence of current facts.

Weekly reports require a freshly reconciled active Plus/Pro subscription, recent activity and explicit schedule/domain consent. They persist ten sections with sources and missing-data statements. Financial facts cover the completed period; commitments may cover the following week. Pro receives a larger bounded summary. Opening history never generates a report. Once a paid request has been reserved, an interrupted report is not automatically regenerated. The shared worker dispatch is documented separately.

Research requires explicit per-request consent, a paid entitlement and its own flag/budget. One [Brave web search](https://api-dashboard.search.brave.com/app/documentation/web-search) returns at most five snippets; one optional model summary follows. No linked page is fetched. Unsafe URL schemes, IP literals, credentials and local hostnames are rejected. Search excerpts and retrieval time are distinguished from verified facts and publication time. [Brave pricing](https://api-dashboard.search.brave.com/documentation/pricing) lists $5/1,000 searches and conditional $5 monthly credits; costs are reserved without assuming credits.

Voice activation remains a separate approval gate. Real provider quality, grounded-answer usefulness, actual token costs and live hosted scheduling still require synthetic/consented beta acceptance with commercial credentials. Mocked tests establish isolation and control flow, not production usefulness or uptime.

## Feature-flagged voice implementation
Voice uses canonical PCM16 mono 16kHz WAV, a 30-second recording maximum, a 15-minute customer session, explicit microphone/data consent and current domain permissions. The server derives duration from validated sample bytes; a client cannot understate it. Only an active fresh Plus/Pro subscription can start; atomic transcription and answer reservations occur before either provider call. Every answered recording also uses one AI message, and voice quota measures recorded input seconds. Raw audio is not saved; owned transcripts/answers are included in portability export. Replay never re-dispatches paid calls. Stop/expiry and changed sharing permission block subsequent work.
The initial architecture uses gpt-4o-mini-transcribe plus the grounded text model. Official token pricing is USD 1.25/M input and 5/M output; the 0.003/min figure is an estimate. Reservations conservatively cover the documented 16k context and 2k output limits, not only estimated minutes. Optional spoken playback selects only browser voices reporting localService=true. No paid TTS or realtime service is invoked. Device availability and local-voice privacy require real-device review. This is an initial low-cost implementation, not a measured usability winner. Cost approval (PLUTO_VOICE_COST_APPROVED=approved), voice/chat flags, provider keys, budgets and live usability/expense acceptance are all required before activation.
Sources: https://developers.openai.com/api/docs/models/gpt-4o-mini-transcribe and https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService


## Operator configuration required before paid activation

The app no longer supplies a default chat model, transcription model, token price or search-call cost. Configure PLUTO_CHAT_MODEL and both PLUTO_AI_*_MICROS_PER_MILLION rates explicitly. Voice additionally requires PLUTO_TRANSCRIPTION_MODEL and both PLUTO_TRANSCRIPTION_*_MICROS_PER_MILLION rates; use the highest applicable input rate across the chosen model's audio/text input categories. Research requires PLUTO_RESEARCH_CALL_MICROS. All rates are integer USD microdollars (one dollar = 1,000,000 microdollars), with token rates expressed per million tokens. Values in unit tests are synthetic fixtures, not recommended provider prices.

Verify model support, response/usage shapes and current standard-tier rates in official provider documentation before enabling any paid flags. An API key alone does not enable paid use. Existing consent, canonical plan entitlement, database BudgetPolicy, request/token/global limits and provider-side spending controls still apply. Voice reserves 125% of the configured maximum 16,000 input +2,000 output token cost for transcription instead of a fixed assumed dollar amount. Missing/invalid model rates stop voice before session creation or microphone use can begin. Local mocked tests do not establish account model access or invoice accuracy.

Official pricing reference reviewed: https://developers.openai.com/api/docs/pricing . No paid request was made.
