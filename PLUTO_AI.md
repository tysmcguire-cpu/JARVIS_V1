# Pluto intelligence

Text chat, persisted customer conversations, bounded read-only data tools, weekly report history and explicit public web research are implemented. All paid flags default OFF. Local analysis remains available without sending records to a provider. Full note bodies, connector tokens and other customers' records never enter model context. Domain-specific sharing consent is separate from the selected question scopes. Facts and exact calculations remain immutable; model interpretations are labelled estimates or suggestions and validated against supplied references. No SQL, code or unrestricted action tools are exposed.

The initial provider uses the Responses API, strict structured output, `store:false`, standard service tier, a 20-second timeout and at most 1,400 output tokens. Configurable default `gpt-6-luna` costs USD $0.10/M input and $0.50/M output tokens according to [official model documentation](https://developers.openai.com/api/docs/models/gpt-6-luna). Unknown model names require explicit positive input/output microdollar rates. Confirm actual project availability and current prices before activation. ChatGPT Plus does not fund API requests.

Every paid request first atomically reserves requests, tokens, concurrency and conservative cost against customer and global budgets. Provider usage settles inside the same transaction as saved results. Failed or uncertain dispatch retains worst-case cost; replay keys never redispatch. Context and responses have byte limits. Providers never receive database credentials. Historical user messages are bounded conversational context, not evidence of current facts.

Weekly reports require a freshly reconciled active Plus/Pro subscription, recent activity and explicit schedule/domain consent. They persist ten sections with sources and missing-data statements. Financial facts cover the completed period; commitments may cover the following week. Pro receives a larger bounded summary. Opening history never generates a report. Once a paid request has been reserved, an interrupted report is not automatically regenerated. The shared worker dispatch is documented separately.

Research requires explicit per-request consent, a paid entitlement and its own flag/budget. One [Brave web search](https://api-dashboard.search.brave.com/app/documentation/web-search) returns at most five snippets; one optional model summary follows. No linked page is fetched. Unsafe URL schemes, IP literals, credentials and local hostnames are rejected. Search excerpts and retrieval time are distinguished from verified facts and publication time. [Brave pricing](https://api-dashboard.search.brave.com/documentation/pricing) lists $5/1,000 searches and conditional $5 monthly credits; costs are reserved without assuming credits.

Voice activation remains a separate approval gate. Real provider quality, grounded-answer usefulness, actual token costs and live hosted scheduling still require synthetic/consented beta acceptance with commercial credentials. Mocked tests establish isolation and control flow, not production usefulness or uptime.
